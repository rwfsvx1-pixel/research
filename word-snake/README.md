# 🐍🌧️ Word Snake — 코코와 비 오는 날

초등학교 4학년을 위한 영어 학습 게임입니다. **산성비**(하늘에서 떨어지는 낱말)와 **스네이크**(먹으면 길어지는 뱀)를 합쳐,
낱말을 순서대로 먹으면 뱀의 몸이 그대로 영어 문장이 됩니다. 문장을 완성할 때마다 이야기 장면의 그림 조각과 대사가 하나씩 채워집니다.

## 실행

빌드 과정이 없는 정적 웹앱입니다.

```bash
cd word-snake
python3 -m http.server 8000   # http://localhost:8000
```

### 휴대폰에서 하기 (GitHub Pages)

1. GitHub 저장소 → **Settings → Pages**
2. **Source**: Deploy from a branch → 이 게임이 있는 브랜치, 폴더 `/ (root)` → Save
3. 1~2분 뒤 `https://<계정>.github.io/research/` 를 휴대폰 크롬/사파리로 연다.
4. 브라우저 메뉴의 **홈 화면에 추가**를 누르면 앱처럼 쓸 수 있다.

카카오톡 안에서 링크를 열면 마이크·공유가 막힐 수 있으니 "다른 브라우저로 열기"를 눌러 크롬/사파리에서 여세요.

마이크(따라 말하기)는 `https://` 또는 `localhost`에서만 동작합니다. 휴대폰에서 쓰려면 GitHub Pages 같은 HTTPS 호스팅에 올리세요.

## 놀이 흐름

| 단계 | 내용 |
|---|---|
| 낱말 | 장면마다 새 낱말 5개. 그림+우리말을 보고 떨어지는 영어 낱말을 찾아 먹는다. |
| 문장 | 영어 문장을 듣고, 낱말을 **순서대로** 먹어 문장을 만든다. 장면이 뒤로 갈수록 문장이 길어진다 (1낱말 → 7낱말). |
| 장면 | 문장 하나 = 대사 하나 + 그림 조각 하나. 5문장이면 장면 완성. |
| 이야기책 | 완성한 장면을 대화로 다시 듣기, **역할놀이**(준/코코 역을 맡아 직접 말하기), 이야기 보내기. |
| 말하기 | 문장 듣기(보통/천천히) → 따라 말하고 녹음 → 내 목소리 듣기 → 공유 창에서 카카오톡으로 전송. |
| 기억 복습 | 장면 그림과 앞 대사를 보고 다음 대사를 떠올려 낱말 조각으로 다시 만든다. 간격 반복(1·2·4·7·14·30일). |
| 학습 기록 | 연속 일수, 장면/문장/낱말 수, 문장별 기억 정도와 다음 복습일. |

틀린 낱말을 먹거나 필요한 낱말을 땅에 떨어뜨리면 하트가 줄고, 헤매면 정답 낱말이 반짝여서 도와줍니다.

## 써니타운 · 나의 영어 마을 (본편)

`village.html`. 영어만 쓰는 작은 마을로 이사 와서 이웃과 대화하며 하루하루 사는 게임입니다.

- **오늘의 일**: 날마다 이웃 두 명과 할 일이 생깁니다 (인사하기, 빵 사기, 생일 축하하기 …). 다 하고 내 방에서 자면 다음 날이 옵니다.
- **대답하기**: 하고 싶은 말(우리말)을 고르면 낱말 조각으로 영어 문장을 만들어 말합니다. AI가 연결되어 있으면 직접 써도 되고, 한국어로 쓰면 영어로 어떻게 말하는지 알려 줍니다.
- **기억하는 이웃**: 내가 한 말(좋아하는 것, 생일 …)을 이웃이 기억했다가 다음 대화에 씁니다. 예전에 말한 표현은 며칠 뒤 다시 쓸 기회가 옵니다(간격 반복).
- **내 방 / 내 표현**: 이웃이 준 선물이 방에 쌓이고, 내가 직접 말한 문장이 표현 수첩에 모입니다. 다시 듣고, 따라 말하고, 녹음을 보낼 수 있습니다.
- **선물 약속**: 부모님과 목표(대화 ○번, ○일 살기, 표현 ○개)와 선물을 정해 두고, 달성하면 카톡으로 알립니다.

## 3D 블록 섬 (시험판)

홈의 **3D 블록 섬 탐험**(`island.html`)은 같은 이야기를 블록 세계로 옮긴 시제품입니다.
하늘에서 떨어져 땅에 박힌 낱말 블록을 캐서 문장을 만들면 다음 섬으로 가는 다리가 놓이고, 다리에는 그 문장이 팻말로 남습니다.
블록은 시간이 지나면 비에 녹습니다. 화면을 누르면 그곳으로 걸어가고, 블록을 누르면 가서 캐고, 끌면 조이스틱처럼 움직입니다.
진행 기록은 2D 게임과 함께 쓰므로 섬에서 만든 문장도 이야기책과 복습에 나옵니다.

## 구조

- `js/data.js` — 이야기 데이터(장면 6개 · 낱말 30개 · 대사 30개). 여기만 고치면 이야기를 늘릴 수 있다.
- `js/game.js` — 캔버스 게임 엔진(낱말 비, 뱀, 충돌).
- `js/audio.js` — TTS, 녹음(WAV 변환), 발음 인식, 공유, 효과음.
- `js/store.js` — 학습 기록과 복습 일정(localStorage).
- `js/village.js` · `js/town.js` · `js/ai.js` — 써니타운 화면, 마을 데이터(주민·대본), AI 연결.
- `server/` — AI 대화용 프록시(Cloudflare Worker).
- `js/island.js` — 3D 블록 섬(three.js, `vendor/three.min.js`).
- `js/ui.js` — 2D와 3D가 함께 쓰는 말풍선 · 말하기 패널 · 알림.
- `js/app.js` — 화면(홈 · 게임 · 이야기책 · 역할놀이 · 복습 · 기록).

## 알아둘 점

- 발음 채점(별점)은 데스크톱 크롬 계열에서만 됩니다. 휴대폰에서는 녹음과 음성 인식이 마이크를 동시에 쓰지 못해 녹음·다시 듣기·보내기만 제공합니다.
- 카카오톡 전송은 브라우저의 공유 기능(Web Share)을 씁니다. 파일 공유를 지원하지 않는 브라우저에서는 녹음 파일을 내려받습니다.
- 기록은 기기(브라우저)에만 저장됩니다.
